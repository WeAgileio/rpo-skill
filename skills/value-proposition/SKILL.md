# Value Proposition

依 Geoffrey A. Moore 的定位方法，為指定產品或服務撰寫七行價值主張。聚焦一個具體客群及其主要需求；可優先選擇灘頭堡客群，並依產品階段調整。預設使用繁體中文，使用者另有指定時從其要求。

## 釐清與確認

1. 整理已知的產品、客群與情境、需求、現有做法、期望結果、替代方案、產品能力及證據，不重問已知資訊。
2. 自行查證相關公開事實，尤其是使用者提出的競品；優先使用官方或可靠的一手來源，附連結並註明適用市場、版本或時間。無法查證時說明。使用者的經驗或決策直接詢問；需要顧客或他人證實的資訊列為待驗證，勿將推測視為事實。
3. 比對查證結果與使用者提供的內容，指出有依據的衝突、共同特點或比較條件不足之處。以中性問題請使用者決定是否調整定位，不自行將推論改寫成事實。
4. 分輪釐清影響定位的未知事項：先問客群、情境、問題、現有做法、期望結果及產品能力，再依回答深入。經驗題請對方舉例，決策題可提供建議及理由；每次只問一個必要問題，等待回答。可自行查證的事項同步處理。
5. 撰寫前摘要目標客群、需求、產品能力、比較對象與主要差異，區分已知資訊與假設，以一個問題請使用者確認或修正；收到回覆後再撰寫。資訊充分時仍須確認摘要，但不重問已確認的選擇。一般的撰寫或優化要求不代表同意跳過確認；若只確認部分內容，其他關鍵假設仍須確認。

使用者明確要求跳過確認、表示時間有限或授權自行假設時，可直接撰寫，並標示影響結論的假設、待驗證事項及需要確認的對象；未回覆不等於確認。

## 撰寫原則

- 區分顧客目前使用的市場替代方案與用於比較的產品替代方案；兩者可能重疊，也可包含現有做法。選擇有意義的比較對象，說明顧客改變現狀的理由。
- 從具體應用情境描述完整產品：除核心產品外，顧客達成預期結果所需的關鍵功能、服務、支援或整合，以及相對於產品替代方案的差異。只描述有依據的能力，未確認的配套列為假設。
- 每行簡潔具體，優先呈現主要價值及差異，避免堆砌功能、空泛優勢或無根據的比較。可使用一個貼近顧客的類比，優先放在最後一句；價格、性能等具體比較仍須查證。
- 七行應能濃縮為容易轉述的一兩個短句。多個目標客群分別撰寫；除非使用者要求，不延伸為其他框架或行銷文案。

## 輸出模板

- **對於**〈目標顧客〉
- **他們**〈對目前市場替代方案的不滿或尚未被滿足的需求〉
- **〈產品或服務名稱〉**
- **是一種**〈概括描述〉
- **能夠**〈解決關鍵問題的能力及顧客購買的主要理由〉
- **不同於**〈用來比較的產品替代方案〉
- **我們的產品**〈針對具體情境的完整產品關鍵功能、必要配套與差異〉

「是一種」可依語意調整。七行後僅在必要時簡短註明假設或待驗證事項。

此格式改寫自 Geoffrey A. Moore《[Crossing the Chasm](https://geoffreyamoore.com/book/crossing-the-chasm)》第三版的六項定位模板；七行格式及類比指引是本技能的調整，並非原文。另參考作者的〈[Using the “Elevator Test”](https://web.stanford.edu/group/e145/cgi-bin/winter/drupal/upload/handouts/MoorePositioning.pdf)〉。
